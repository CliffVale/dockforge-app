Your first docking in 5 minutes

  1. Open the Docking Lab and click “Load the DNA example” — it fills in a real drug–DNA complex (the minor-groove drug netropsin inside a B-DNA dodecamer, PDB 121D)
  2. Press Run Docking in the embedded Webina app. Your computer does the science; nothing is uploaded.
  3. When it finishes, download the poses (.pdbqt) and drag them into the Result Viewer to see where the molecule wants to sit inside the double helix.
  4. Curious why it sits there? That’s exactly what the course explains. 🎓

How this site works

🔒 Private by design

The docking engine is Webina — Vina compiled to WebAssembly. Structures you load or draw never leave your browser. This site itself is static files on GitHub Pages: no accounts, no analytics, no uploads.

🎓 Honest about limits

Browser docking is for learning. Research-grade work needs prepared structures, protonation care, pose validation (e.g. PoseBusters) and much more sampling — see our README for the full open-source pipeline this project is growing into.

⚠️ Health disclaimer: Docking scores are hypotheses, not medical advice. Nothing here should guide treatment decisions — it’s an educational sandbox for structural biology.
